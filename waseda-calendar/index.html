公式情報・掲載ルール

一次情報は早稲田大学ア式蹴球部｜男子部の試合結果。男子部の月間予定と照合しています。

  • 対象：男子TOPの関東大学リーグ、総理大臣杯、アミノバイタルカップ、定期戦など。FC、Iリーグ、女子、練習試合は除外。
  • 主ソースと月間予定に食い違いがある場合、主ソースを優先し警告を記録。
  • 日時未定は勝手に日付・時刻を補完しません。日時の確定していない試合はiCalに含めません。
  • 表示結果は公式サイトの更新状況に依存します。会場・開始時刻の最終確認は公式情報をご参照ください。
更新方法・このサイトについて

GitHub Actionsにより毎日自動更新。管理者は更新ワークフローから手動実行できます。公式サイトに接続できない場合や検証が失敗した場合、前回公開データを保持します。

本サイトはファンによる非公式プロジェクトであり、早稲田大学ア式蹴球部および大会主催者の公式サービスではありません。
